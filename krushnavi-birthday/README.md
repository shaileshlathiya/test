# Krushnavi's birthday status videos

Three 9:16 birthday status videos (WhatsApp / Instagram story) made from 19 real family photos.
Her face is never altered: every frame only crops, scales, frames or masks the original photos
(no AI generation, no retouching). Crops are face-safe by construction (the engine knows where
each face is and keeps it inside the frame).

| File | Style | Length | Photos |
|------|-------|--------|--------|
| `videos/krushnavi_v1_golden_celebration.mp4` | Golden Celebration: navy/plum background, gold typography, gold-ringed hero intro, collages for Mumma / Papa / family, balloon finale | 29.6 s | 16 |
| `videos/krushnavi_v2_pastel_scrapbook.mp4` | Pastel Scrapbook: cream paper, polaroids with hand-written captions and washi tape, six scrapbook pages, hug finale | 29.5 s | 19 |
| `videos/krushnavi_v3_cinematic_family_story.mp4` | Cinematic Family Story: warm film look, five chapters (Our Sunshine, Little Explorer, Mumma's Love, Daddy's Girl, Family & Festivals), gold end card | 57.8 s | 19 |

All files are 1080x1920, 30 fps, H.264 + AAC. The music is a synthesized music-box
"Happy Birthday" (public-domain melody, generated by `engine/music.py`); replace the audio
track in any editor if you prefer a different song. V1 and V2 fit the 30 s WhatsApp status
limit; V3 fits the 60 s limit.

## Re-rendering

```
engine/
  bday_engine.py      shared rendering engine (Pillow + numpy -> ffmpeg)
  music.py            music-box Happy Birthday synthesizer
  fetch_fonts.sh      downloads the Google Fonts the scripts use into engine/fonts/
  assets/photos.json  per-photo face boxes used for face-safe cropping
  versions/           one script per video (v1_golden.py, v2_scrapbook.py, v3_cinematic.py)
```

The source photos are not stored in the repository. To re-render:

1. Install Python 3.11+ with `pillow` and `numpy`, and `ffmpeg` (6.x).
2. Put the 19 photos in `engine/assets/photos/` as `p01.jpg` ... `p19.jpg`, in the same order
   they were shared, each resized/cropped to 1620x2160 (3:4). `assets/photos.json` holds the
   normalized face boxes for exactly these framings; if you use different crops, update it.
3. `cd engine && ./fetch_fonts.sh`
4. Generate the music tracks (V3 generates its own on first run):
   `python3 music.py 30 assets/audio/hb_30s.wav` and `python3 music.py 30.7 assets/audio/hb_v2_307.wav`
5. Render: `python3 versions/v1_golden.py` (likewise `v2_scrapbook.py`, `v3_cinematic.py`).
   Output lands in `engine/out/`. Each script also accepts `--preview` (contact sheets only,
   no encode); V1 and V2 have a `--check` mode that verifies face/text/safe-zone geometry.

Set `BDAY_DIR` to point the scripts at a different engine folder if needed.
